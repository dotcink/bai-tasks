# 租房信息评估标准 (Evaluation Criteria)

## 基础筛选规则 (Basic Filtering)
1. **地理位置**：必须位于上海“周浦”地区，或者包含明确的周浦地标/楼盘（如：周浦万达、印象春城、浦发东悦城、逸致璟庭、繁荣馨苑等）。
2. **房型要求**：明确标注为“二居室”或“三居室”（两室、三室、2房、3房等）。
3. **发布时间**：最近 2 个月内发布的信息（以当前日期为基准回溯）。
4. **信息类型**：必须是“出租”信息，**严格排除“求租”信息**。

## 详细数据字段提取标准 (Data Dimensions)
1. **价格 (Price)**：
   - 提取月租金数值（如 3850）。
   - 识别单位：元、k、/月。
2. **小区 (Compound)**：
   - 准确识别小区全称（如：繁荣馨苑）。
   - 优先匹配已知周浦小区列表。
3. **户型 (Layout)**：
   - 识别几室几厅（如：两房两厅）。
4. **宠物政策 (Pet Friendly)**：
   - 明确标注不可养、不养宠则为“否”。
   - 明确标注可养、宠物友好则为“是”。
   - 正文未提及宠物限制则默认标记为“未知”（不主动剔除）。
5. **租赁方式 (Rental Type)**：
   - 包含“房东直租”、“业主直租”、“个人房源”等关键词标记为“直租”。
   - 包含“中介”、“中介费”、“费”等关键词标记为“中介”。
   - 无法判定时标记为“中介/未知”。

## 数据管理要求
1. **内容提取**：必须抓取完整的笔记正文内容，以便人工核实。
2. **目标位置**：
   - 本地备份：`zhoupu_renting_detailed.csv`。
   - 在线管理：飞书电子表格 [上海周浦租房信息](https://ycnuavhumwlq.feishu.cn/sheets/L4xPswHvXhQYAAtOzNYc5D4ynmg)。
3. **更新逻辑**：每次抓取结果应以“追加 (Append)”方式同步至飞书，保持历史记录。
